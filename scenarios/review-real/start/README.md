# review-real

A scenario repository of the Kanon e2e harness: the real-model tier (Kanon plan 0012 §6.2, step
E10), at Kanon `{{release}}`, in `{{repository}}`. The harness installed Kanon's `review` feature
here, opened a one-line documentation pull request, had the test Author label it `review:please`,
let the Reviewer review it on the model, checked that a verdict was posted, and deletes the
repository.
