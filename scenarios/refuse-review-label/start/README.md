# refuse-review-label

A scenario repository of the Kanon e2e harness: a gate refusal (Kanon plan 0012 step E12), at
Kanon `{{release}}`, in `{{repository}}`. The harness installed Kanon's `review` feature here,
labelled a pull request `review:please` as an App outside the App register, checked that the
review lane started nothing, and deletes the repository.
